# 常见问题

## 什么是 Spine Cloud？

Spine Cloud 是一项通过 CLI 部署使用 Go 编写的 Spine 应用并在网页控制台中管理的服务。你可以查看部署历史和成功部署的公开地址。

## 如何开始使用？

在[控制台](https://spinecloud.dev/)创建账户并阅读服务条款。在 CLI 中运行 `spine cloud auth login`，然后在浏览器中批准一次性代码，即可连接同一账户。

## 可以部署哪些应用？

Spine Cloud 面向使用 Go 编写的 Spine 应用。部署需要受支持的 CLI、符合条件的账户和可用的部署目标。

## 如何部署应用？

连接账户后，在 CLI 中运行 `spine deploy` 并选择应用。CLI 会显示部署进度和结果。请求已接收不代表部署已完成。

## 在哪里查看应用地址？

部署成功后，可以在 CLI 的结果和控制台的部署历史中查看公开地址。

## 如何收费？

公开测试期间所有功能免费。如果以后推出付费功能，会在付款前说明价格和使用条件。详情请参阅[服务条款](https://spinecloud.dev/terms)。

## Spine 框架和 Spine Cloud 有什么区别？

Spine 框架以 MIT 许可证提供。Spine Cloud 是用于部署和管理 Spine 应用的独立服务。
