# 架构与服务提供商

Spine Cloud 通过 CLI 接收部署请求，使用管理 API 和执行代理运行应用。下图仅显示逻辑路径，不含凭据或内部地址。

<ArchitectureMap />

## 组件与提供商

| 组件 | 职责 | 已记录环境 |
| --- | --- | --- |
| Spine CLI | 账户连接、构建和部署 | 开发者环境中的 Preview 开发版 CLI |
| 控制台 | 账户批准、应用和历史 | Vercel 上的 React |
| 管理 API | 身份验证、所有权、任务和状态 | Railway |
| 身份与存储 | 认证、元数据和私有构建产物 | Supabase |
| 代理 | 查询、校验、运行和报告 | OCI |
| Portal | 将公开 HTTPS 流量转发至应用 | 自行运营的中继与隧道 |


## 部署与流量

在浏览器批准一次性代码后运行 `spine deploy`。API 检查所有权和格式，加密并私有存储产物。代理通过已认证的 HTTPS 查询并领取任务，解密后校验哈希和格式，再启动应用。内部健康检查和公开 HTTPS 检查完成后记录成功状态和地址。请求已接收不等于应用已运行。

## 开发者须知

还应考虑数据库连接、密钥轮换和日志中的敏感信息。
