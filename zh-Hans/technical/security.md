# 安全与数据

## 账户与 CLI 认证

CLI 登录使用浏览器批准、有效期五分钟的一次性代码，只有持有设备密钥的 CLI 能接收结果。网页与 CLI 会话分离。测试拒绝了未认证批准、其他设备密钥、重复批准和重复领取。请求限制目前按 API 进程实施；增加副本前需要共享限制和滥用监控。

## 访问与构建产物

API 检查所有权。内部示例测试拒绝了其他账户访问应用和历史，以及私有产物请求。产物使用 gzip 压缩、AES-256-GCM 加密后存入 Supabase Storage 私有存储桶。代理解密后校验哈希和格式。密钥轮换、恢复和最小权限凭据需要进一步运维验证。

## 环境变量与日志

本地实现使用 AES-256-GCM 加密值，并将应用 ID 和变量名作为认证数据。所有者可查看名称，但不能取回已存储的值；更改在下次部署时生效。此路径尚未部署到生产环境。应用可能将密钥输出到日志，应避免这样做。

## 隔离限制

示例验证不能证明任意客户代码间的隔离，也不能证明对主机、中继和凭据的访问被阻止。多租户隔离和实际运维路径须在公开测试前验证。独立认证、审计和事件响应时间尚无保证，安全报告渠道与响应政策尚未确定。
