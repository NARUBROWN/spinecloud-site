# 安全与数据

## 账户与 CLI 认证

CLI 登录使用浏览器批准、有效期五分钟的一次性代码，只有持有设备密钥的 CLI 能接收结果。网页与 CLI 会话分离。请求限制目前按 API 进程实施。

## 访问与构建产物

API 检查所有权。产物使用 gzip 压缩、AES-256-GCM 加密后存入 Supabase Storage 私有存储桶。代理解密后校验哈希和格式。

## 环境变量与日志

环境变量的值使用 AES-256-GCM 加密，并将应用 ID 和变量名作为认证数据。所有者可查看名称，但不能取回已存储的值；更改在下次部署时生效。应用可能将密钥输出到日志，应避免这样做。

## 运行环境的安全边界

不保证应用间隔离，也不保证阻止对主机、中继和凭据的访问。
