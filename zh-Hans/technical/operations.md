# 运维与恢复

## 状态与可观测性

本地实现区分代理报告的服务状态、内部健康检查和公开地址检查。报告过期或时间不可信时不显示当前状态和使用率。部署成功不保证应用当前仍在运行。

本地实现收集最近的应用日志。保存新测量值时删除旧数据，但收集停止时删除也会停止，因此不保证固定时间删除。保留期限和独立过期任务尚未决定。

## 资源政策

本地政策为 32 MiB 基准、64 MiB 硬限制、连续超过基准 30 秒触发限制。在 QEMU 的 Ubuntu ARM64 中测试了 systemd 凭据传递与限制，但这不能证明完整 OCI 部署或多客户并发容量。该政策尚未部署到生产环境，也不保证性能或容量。

## 替换与恢复

本地实现会在内部健康或公开连接检查失败时恢复先前的可执行文件和配置，中断后的协调逻辑经过隔离测试。真实代理替换、OCI 重启和经过 Portal 的完整恢复尚未验证。迁移假设现有部署 ID 与运行服务 ID 一致，应用前必须确认。现有应用与产物允许列表仍然保留。

## 服务限制

单台 VM 故障可能同时影响多个应用和相关组件。备份恢复、租户隔离、多应用负载、证书续期与事故流程仍需验证。服务水平、恢复目标和保留期限尚未确定。
