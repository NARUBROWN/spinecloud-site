# 安全與資料

## 帳戶與 CLI 驗證

CLI 登入使用瀏覽器核准、有效期五分鐘的一次性代碼，只有持有裝置密鑰的 CLI 能接收結果。網頁與 CLI 工作階段分開。請求限制目前按 API 程序實施。

## 存取與建置產物

API 檢查所有權。產物使用 gzip 壓縮、AES-256-GCM 加密後存入 Supabase Storage 私人儲存桶。代理程式解密後驗證雜湊和格式。

## 環境變數與日誌

環境變數的值使用 AES-256-GCM 加密，並將應用程式 ID 和變數名稱作為驗證資料。擁有者可查看名稱，但無法取回已儲存的值；變更在下次部署時生效。應用程式可能將密鑰輸出到日誌，應避免這樣做。

## 執行環境的安全邊界

不保證應用程式間的隔離，也不保證阻止對主機、中繼和憑證的存取。
