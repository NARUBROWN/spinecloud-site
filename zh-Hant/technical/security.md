# 安全與資料

## 帳戶與 CLI 驗證

CLI 登入使用瀏覽器核准、有效期五分鐘的一次性代碼，只有持有裝置密鑰的 CLI 能接收結果。網頁與 CLI 工作階段分開。測試拒絕了未驗證核准、其他裝置密鑰、重複核准和重複領取。請求限制目前按 API 程序實施；增加副本前需要共用限制和濫用監控。

## 存取與建置產物

API 檢查所有權。內部範例測試拒絕了其他帳戶存取應用程式和歷程，以及私人產物請求。產物使用 gzip 壓縮、AES-256-GCM 加密後存入 Supabase Storage 私人儲存桶。代理程式解密後驗證雜湊和格式。金鑰輪替、復原和最小權限憑證需要進一步維運驗證。

## 環境變數與日誌

本機實作使用 AES-256-GCM 加密值，並將應用程式 ID 和變數名稱作為驗證資料。擁有者可查看名稱，但無法取回已儲存的值；變更在下次部署時生效。此路徑尚未部署至正式環境。應用程式可能將密鑰輸出到日誌，應避免這樣做。

## 隔離限制

範例驗證不能證明任意客戶程式碼間的隔離，也不能證明對主機、中繼和憑證的存取已被阻止。多租戶隔離和實際維運路徑須在公開測試前驗證。獨立認證、稽核和事件回應時間尚無保證，安全通報管道與回應政策尚未確定。
