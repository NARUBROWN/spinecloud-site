# 維運與復原

## 狀態與可觀測性

本機實作區分代理程式回報的服務狀態、內部健康檢查和公開網址檢查。回報過期或時間不可信時不顯示目前狀態和使用率。部署成功不保證應用程式目前仍在執行。

本機實作收集最近的應用程式日誌。儲存新測量值時刪除舊資料，但收集停止時刪除也會停止，因此不保證固定時間刪除。保存期限和獨立過期工作尚未決定。

## 資源政策

本機政策為 32 MiB 基準、64 MiB 硬限制、連續超過基準 30 秒觸發限制。在 QEMU 的 Ubuntu ARM64 中測試了 systemd 憑證傳遞與限制，但這不能證明完整 OCI 部署或多客戶並行容量。該政策尚未部署至正式環境，也不保證效能或容量。

## 替換與復原

本機實作會在內部健康或公開連線檢查失敗時復原先前的執行檔和設定，中斷後的協調邏輯經過隔離測試。真實代理程式替換、OCI 重新啟動和經過 Portal 的完整復原尚未驗證。移轉假設現有部署 ID 與執行服務 ID 一致，套用前必須確認。現有應用程式與產物允許清單仍然保留。

## 服務限制

單台 VM 故障可能同時影響多個應用程式和相關元件。備份復原、租戶隔離、多應用程式負載、憑證更新與事故流程仍需驗證。服務水準、復原目標和保存期限尚未確定。
