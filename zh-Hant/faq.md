# 常見問題

## 什麼是 Spine Cloud？

Spine Cloud 是一項透過 CLI 部署以 Go 撰寫的 Spine 應用程式，並在網頁控制台管理的服務。你可以查看部署歷程和成功部署的公開網址。

## 如何開始使用？

在[控制台](https://spinecloud.dev/)建立帳戶並閱讀服務條款。在 CLI 執行 `spine cloud auth login`，再於瀏覽器核准一次性代碼，即可連結同一帳戶。

## 可以部署哪些應用程式？

Spine Cloud 適用於以 Go 撰寫的 Spine 應用程式。部署需要受支援的 CLI、符合條件的帳戶與可用的部署目標。

## 如何部署應用程式？

連結帳戶後，在 CLI 執行 `spine deploy` 並選擇應用程式。CLI 會顯示部署進度與結果。請求已接收不代表部署已完成。

## 在哪裡查看應用程式網址？

部署成功後，可以在 CLI 的結果與控制台的部署歷程中查看公開網址。

## 如何收費？

公開測試期間所有功能免費。如果日後推出付費功能，會在付款前說明價格與使用條件。詳情請參閱[服務條款](https://spinecloud.dev/terms)。

## Spine 框架和 Spine Cloud 有什麼不同？

Spine 框架以 MIT 授權提供。Spine Cloud 是用來部署與管理 Spine 應用程式的獨立服務。
