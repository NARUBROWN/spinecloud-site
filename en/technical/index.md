# Documentation overview

This draft explains how Spine Cloud deploys and operates apps, its security boundaries, and the scope of verification.

::: warning Draft for open beta
Operational results apply to the specified internal example app. They do not establish customer app safety or the current scope of open beta. Verify the deployed configuration and policies before launch.
:::

The basis is project records and local implementation through November 8, 2026. Changes not deployed to production are identified separately. Pricing, service guarantees, retention periods, and an incident contact remain to be decided.
