# Spine Cloud 기술 문서

Spine Cloud가 앱을 배포하고 운영하는 방식, 보안 경계와 검증 범위를 설명합니다. 서비스를 선택할 때 필요한 제약도 함께 기록합니다.

::: warning 문서 상태
이 문서는 오픈 베타를 위해 준비 중인 초안입니다. 아래 운영 검증은 명시된 자체 예제 앱에 대한 결과이며 일반 고객 앱의 안전성이나 오픈 베타의 현재 제공 범위를 보장하지 않습니다. 오픈 베타 공개 전에 실제 배포 구성과 정책을 다시 확인해야 합니다.
:::

- [아키텍처와 제공자](./architecture): 구성 요소, 배포와 요청 경로, 선택 이유
- [보안과 데이터](./security): 인증, 접근 제어, 암호화, 격리의 한계
- [운영과 복구](./operations): 단일 서버의 제약, 상태 확인, 복구와 미검증 항목

검증 기준은 2026년 11월 8일까지의 프로젝트 기록과 로컬 구현입니다. 운영 환경에 적용되지 않은 변경은 별도로 표시합니다. 이용 요금, 서비스 수준 보장, 데이터 보관 기간과 사고 대응 연락처는 확정 후 이 문서에 추가해야 합니다.
