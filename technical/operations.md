# 운영과 복구

Spine Cloud의 상태 표시, 자원 제한과 복구 방식은 앱이 실제로 어떻게 동작하는지 이해하는 데 중요합니다. 이 문서는 상태 확인과 자원 정책, 복구 방식를 설명합니다.

## 상태와 관측

인스턴스 상세 화면은 에이전트가 보고한 서비스 상태, 내부 상태 확인과 공개 주소 상태를 구분합니다. 보고가 오래됐거나 시각을 신뢰할 수 없으면 현재 상태와 사용률을 표시하지 않도록 설계했습니다. 배포 성공이 현재 실행 상태를 보장하지는 않습니다.

앱의 최근 실행 로그를 수집합니다. 새 측정값을 저장할 때 오래된 측정값을 삭제하지만 수집이 멈추면 자동 삭제도 멈춥니다. 따라서 정해진 시간에 데이터가 삭제된다고 보장할 수 없습니다.

## 자원 정책

앱에 기본 메모리 용량이 제공되며, 부스터를 통해 최대 두 배의 용량을 1분 동안 사용할 수 있습니다. 메모리 사용량이 기본 용량을 연속 1분 초과하면 앱이 재시작됩니다.

## 교체와 복구

새 배포의 내부 상태 확인이나 공개 연결이 실패할 때 이전 실행 파일과 설정을 복원하도록 설계됐습니다.

배포할 수 있는 앱과 결과물에는 허용 제한이 적용됩니다.
