# 보안과 데이터

Spine Cloud의 보안은 인증, 소유권 확인, 결과물 보호와 실행 환경의 경계를 함께 다룹니다.

## 계정과 CLI 인증

CLI 로그인은 웹에서 승인하는 일회용 코드를 사용합니다. 코드는 5분 동안 유효하며 기기 비밀값을 가진 CLI만 승인 결과를 받을 수 있습니다. 웹과 CLI는 별도 세션을 사용합니다.

현재 요청 제한은 API 프로세스별로 적용됩니다.

## 앱 접근과 배포 결과물

관리 API는 앱과 배포 요청의 소유권을 확인합니다.

배포 결과물은 gzip으로 압축하고 AES-256-GCM으로 암호화해 Supabase Storage의 비공개 버킷에 저장합니다. 에이전트는 복호화 후 해시와 형식을 다시 확인합니다.

## 환경 변수와 로그

환경 변수 값을 AES-256-GCM으로 암호화하고 앱 ID와 변수 이름을 인증 데이터로 결합합니다. 소유자는 등록된 이름을 확인할 수 있지만 저장한 값은 다시 조회할 수 없습니다. 변경 사항은 다음 배포의 스냅샷에 반영됩니다.

애플리케이션 로그에는 앱이 직접 출력한 비밀값이 포함될 수 있습니다. 민감한 값을 로그에 출력하지 않도록 주의해야 합니다. 상태 수집과 보관 동작은 [운영과 복구](./operations)에 설명합니다.

## 실행 환경의 보안 경계

앱 간 격리와 호스트, 릴레이, 자격 증명에 대한 접근 차단은 보장하지 않습니다.
