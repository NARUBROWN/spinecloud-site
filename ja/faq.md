# よくある質問

## Spine Cloudとは何ですか？

Goで書いたSpineアプリをCLIからデプロイし、Webダッシュボードで管理するサービスです。デプロイ履歴と、成功したデプロイの公開アドレスを確認できます。

## どうすれば利用を始められますか？

Spine Cloudはオープンベータです。デプロイにはpreview版CLIが必要です。Goをインストールした環境で次を実行してください。

```bash
go install github.com/NARUBROWN/spine-cli/cmd/spine@preview
```

[ダッシュボード](https://spinecloud.dev/)でアカウントを作成し、利用規約を確認してください。CLIで `spine cloud auth login` を実行し、ブラウザでワンタイムコードを承認すると、同じアカウントに連携できます。

## どのアプリをデプロイできますか？

Goで書いたSpineアプリが対象です。デプロイには対応CLI、利用可能なアカウントとデプロイ対象が必要です。

## アプリをデプロイするには？

アカウントを連携したら、プロジェクトディレクトリで `spine deploy` を実行します。進行状況と結果はCLIで確認できます。リクエストの受付はデプロイの完了を意味しません。

## アプリのアドレスはどこで確認できますか？

デプロイが成功すると、CLIの結果とダッシュボードのデプロイ履歴で公開アドレスを確認できます。

## 料金はかかりますか？

オープンベータ期間中はすべての機能を無料で利用できます。今後有料機能を導入する場合は、支払い前に料金と条件を案内します。詳しくは[利用規約](https://spinecloud.dev/terms)をご確認ください。

## SpineフレームワークとSpine Cloudの違いは？

SpineフレームワークはMITライセンスで提供されています。Spine CloudはSpineアプリのデプロイと管理のための別サービスです。
